# FastNeura Ecosystem Map

株式会社FastNeuraを中心に、企業・研究機関との関係を2D / 3Dで可視化し、案件の重要性も比較できるGitHub Pages向けアプリです。ビルドは不要で、`index.html` と `data.json` だけで動きます。

## 主な機能

- エコシステムの2D / 3D表示
- 企業、ロゴ画像、カテゴリ、ステータス、メモの登録・編集
- 関係カテゴリを保ったまま、関係ごとの任意名称を設定
- 閲覧モード／編集モードの切替（ログイン・アクセストークン不要）
- 案件評価モードの2D / 3Dポジショニング
- 案件評価の軸を6項目から2～3個選択
- JSONのインポート／エクスポート

## 案件評価項目

- 得られそうな金額（万円）
- 受注の確度（%）
- PoC後の継続性（1～5）
- 社内の技術アセットとの親和性（1～5）
- 他案件や企業への応用性（1～5）
- 案件の面白さ（1～5）

評価項目はすべて任意です。現在選択している軸の値が入力済みの案件だけがマップに表示されます。案件は既存の企業IDに紐づき、企業名・ロゴ・カテゴリ色をそのまま利用します。

## データの保存と共有

編集内容は操作中のブラウザに保存されます。チームで共有する場合は、右上の `⋯` から「JSONをエクスポート」を実行し、ダウンロードした `data.json` でリポジトリの同名ファイルを置き換えてください。

静的なGitHub PagesからGitHubへ直接書き込む機能はありません。そのため、アクセストークンの入力も不要です。

## GitHub Pagesで公開

1. リポジトリのルートに `index.html` と `data.json` を置きます。
2. GitHubの `Settings` → `Pages` を開きます。
3. 公開元として対象ブランチ（通常は `main`）と `/ (root)` を選びます。
4. 表示された公開URLを開きます。

`owner.github.io/repository/` 形式のURLでは、公開中のリポジトリと `data.json` の場所を自動認識します。

## データ構造

`data.json` は次の3配列を持ちます。

- `companies`: 企業・研究機関
- `relations`: 企業間の関係
- `projects`: 企業に紐づく案件評価

既存の `companies` と `relations` はそのまま利用でき、`projects` がない旧データも自動的に空配列として読み込まれます。

## 外部ライブラリ

three.js、3d-force-graph、force-graphをCDNから読み込むため、表示時にインターネット接続が必要です。
