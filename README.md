# FastNeura Ecosystem Map

株式会社FastNeuraを中心に、企業・研究機関との関係を2D / 3Dで可視化し、案件の重要性も比較できるGitHub Pages向けアプリです。ビルドは不要で、`index.html` と `data.json` だけで動きます。

## 主な機能

- エコシステムの2D / 3D表示
- 企業、ロゴ画像、カテゴリ、ステータス、メモの登録・編集
- 関係カテゴリを保ったまま、関係ごとの任意名称を設定
- 閲覧モード／編集モードの切替
- GitHub上の `data.json` への自動保存と定期同期
- 案件評価モードの2D / 3Dポジショニング
- 案件評価の軸を6項目から2～3個選択
- JSONのインポート／エクスポート

## 案件評価項目

- 得られそうな金額（万円）
- 受注の確度（%）
- PoC後の継続性（1～5）
- 社内の技術アセットとの親和性（1～5）
- 他案件や企業への応用性（1～5）
- 案件の面白さ（1～5）

評価項目はすべて任意です。現在選択している軸の値が入力済みの案件だけがマップに表示されます。案件は既存の企業IDに紐づき、企業名・ロゴ・カテゴリ色をそのまま利用します。

## データの保存と共有

閲覧者はGitHub上の `data.json` を読み込み、一定間隔で最新版を取得します。編集者の変更は少し待ってからまとめられ、GitHubへ1コミットとして自動保存されます。同時編集時はリポジトリの最新版へ自分の変更だけを重ね、競合した場合は再取得して再試行します。

右上の `⋯` からGitHubのオーナー、リポジトリ、ブランチ、データファイルのパス、アクセストークンを設定してください。トークンがない利用者は閲覧モードになります。

### アクセストークン

GitHubの `Settings` → `Developer settings` → `Personal access tokens` → `Fine-grained tokens` から発行します。

- Repository access：このリポジトリだけを選択
- Repository permissions：`Contents` を `Read and write`
- 有効期限：必要な期間だけに設定

トークンは入力したブラウザのlocalStorageにだけ保存され、`index.html` や `data.json` には含まれません。共有PCでは入力しないでください。編集者ごとに別のトークンを発行すると、GitHubのコミット履歴から更新者を確認できます。

JSONのインポート／エクスポートは、バックアップや一括更新にも利用できます。

## GitHub Pagesで公開

1. リポジトリのルートに `index.html` と `data.json` を置きます。
2. GitHubの `Settings` → `Pages` を開きます。
3. 公開元として対象ブランチ（通常は `main`）と `/ (root)` を選びます。
4. 表示された公開URLを開きます。

`owner.github.io/repository/` 形式のURLでは、公開中のリポジトリと `data.json` の場所を自動認識します。

## データ構造

`data.json` は次の3配列を持ちます。

- `companies`: 企業・研究機関
- `relations`: 企業間の関係
- `projects`: 企業に紐づく案件評価

既存の `companies` と `relations` はそのまま利用でき、`projects` がない旧データも自動的に空配列として読み込まれます。

## 外部ライブラリ

three.js、3d-force-graph、force-graphをCDNから読み込むため、表示時にインターネット接続が必要です。
